DOMINION OF COMMUNION 1.0 — ENDOWMENT STABILITY TEST
=====================================================

ENDOWMENT ROOT-CAUSE FIX
------------------------
- Endowment tier is now locked separately from length and girth. Normal profile refreshes restore the permanent tier instead of recalculating it, so Alpha Check and Tantalize cannot reclassify a character.
- Ruler Designer initialization is protected from pre-lobby title/court hooks. A custom ruler can no longer receive a random profile during game setup before Dominion has honored the selected tier.
- Exact dimensions use the previously working dynamic trait description again.
- Rebuild Endowment Display deliberately clears only the derived tier lock and recomputes from the existing permanent measurements. Reroll All Endowments remains the only operation that intentionally replaces the measurements themselves.

DOMINION OF COMMUNION 1.0.1
===========================

HOTFIX
------
- Endowment tiers are now mutually exclusive in Ruler Designer. Selecting one penis-size tier prevents selecting any of the other five, avoiding invalid multi-tier custom rulers and the resulting startup crash.
- No gameplay systems, Carnalitas hooks, measurements, preferences, interactions, or Ledger behavior were otherwise changed.
